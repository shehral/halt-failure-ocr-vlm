# Loader (mandatory lm_head tie-fix — transformers-version-sensitive, applied unconditionally):
#   The public checkpoint omits `lm_head.weight` and relies on `tie_word_embeddings`.
#   The tie is read off the OUTER config (False) instead of `text_config` (True) on the
#   transformers lines we touched (this is a known no-op on transformers 5.x and is
#   defended against here on the pinned 4.57.6 by setting the flag explicitly), so without
#   the fix `tie_weights()` becomes a no-op, `lm_head` stays at meta-init zeros, and
#   greedy generation collapses to "!" forever. Every loader MUST do, before `.to(device)`:
#
#       from transformers import AutoModelForImageTextToText, AutoProcessor
#       model = AutoModelForImageTextToText.from_pretrained(
#           "nanonets/Nanonets-OCR2-3B",
#           revision="c3886ff00bb037ce7da24988c9eafaf1fe2bed72",
#       )
#       model.config.tie_word_embeddings = True
#       model.tie_weights()
#       assert model.lm_head.weight.data_ptr() == model.model.language_model.embed_tokens.weight.data_ptr()
#       model = model.to(device)
